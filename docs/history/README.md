# History

Documents that explain where Molt came from. They are kept for the record and are **not**
part of the published crate; nothing in them is a promise about Molt today. For current
behaviour read the [`README`](../../README.md), [`SECURITY.md`](../../SECURITY.md),
[`MIGRATION.md`](../../MIGRATION.md) and [`CHANGELOG.md`](../../CHANGELOG.md).

| file | what it is |
| --- | --- |
| [`PORTING.md`](PORTING.md) | how Molt differed from Winged-Swift, the Swift library it began as a port of, and why each difference exists |
| [`MOLT_SPEC.md`](MOLT_SPEC.md) | the original specification the port started from. Several parts were found wrong and were not followed; `PORTING.md` says which |
| [`upstream-findings.md`](upstream-findings.md) | what porting found that was unsafe or wrong in Winged-Swift, and where it was reported |

Winged-Swift is to be discontinued after Molt 1.0.0. The plans that led here are in
[`../plans`](../plans).
